### 🧠 About Me

🔍 **Cyber Security Enthusiast & Full-Stack Developer** passionate about building secure and scalable applications.  
📍 Based in **Kahramanmaraş, Türkiye**, honing my skills for **12+ years** in both hardware and software domains.  
🛡️ I combine an **offensive security mindset** with **defensive coding** practices to build robust systems.  
🎨 My passion for **AI** goes far beyond image generation — I'm deeply into **speech-to-text, text-to-speech, local AI model deployment, and team workflows**, all aimed at making people's daily tasks easier.  
📹 I have comprehensive field experience in **camera systems** (IP/Analog) installation, configuration, management, and **end-user technical support**.  
🐧 Comfortable working in both **Linux** and **Windows** environments; I love automating everything with **Bash** scripts.  
💬 Let’s talk about:  
- 📂 Efficient data and automation pipelines  
- 🎤 Speech-to-Text & Text-to-Speech solutions  
- 🧠 Local AI model deployment & team collaboration  
- 🔒 Secure software development & ethical hacking  
- 🖼️ Turning imagination into visuals with **ComfyUI**
